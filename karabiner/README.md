# Karabiner-Elements — клавиатура

Конфиг: [`karabiner.json`](karabiner.json). Открыть: `karaconf` (fish), но
удобнее менять через само приложение Karabiner-Elements — оно пишет в этот же
файл, и изменения применяются сразу.

## Что переназначено

| Нажимаешь | Получаешь | Зачем |
|---|---|---|
| `Caps Lock` | `Control` | Ctrl под мизинцем: tmux (`Caps-b`), Neovim, терминал |
| `Left Control` | `Caps Lock` | Caps всё ещё доступен |
| `Fn + H/J/K/L` | ← ↓ ↑ → | Стрелки в стиле vim **в любом приложении** |
| Двойной `Fn` | Контекстное меню (`Shift+Fn+F10`) | Правый клик с клавиатуры |

## Как поменять

- Простые замены клавиш — Karabiner → **Simple Modifications**.
- Сложные правила (сочетания, двойные нажатия) — Karabiner → **Complex
  Modifications** → Add rule. Готовые правила: Add predefined rule → Import more
  rules from the Internet.
- Посмотреть, какой код у клавиши, — приложение **Karabiner-EventViewer**.
- Старые версии конфига Karabiner сам кладёт в `automatic_backups/` (в git не
  попадают).

После переустановки macOS попросит разрешения для Karabiner (Мониторинг
ввода, Универсальный доступ, системное расширение) — без них переназначения не работают.

## Внешняя клавиатура (PC) и мышь

На клавиатуре для Windows клавиши стоят в другом порядке (Ctrl, **Win**, **Alt**), чем
на Mac (Control, **Option**, **Command**). Чтобы пальцы попадали туда же, для
подключённых PC-клавиатур заданы правила на уровне устройства (`devices` в
`karabiner.json`; на встроенную клавиатуру они не действуют):

| Клавиша на PC-клавиатуре | Работает как |
|---|---|
| **Win** (левая) | Option — на неё завязаны хоткеи AeroSpace (`Win+h/j/k/l`, `Win+<буква>`) |
| **Alt** (левая) | Command — копировать, вставить и т.п. на привычном месте |
| **Alt** (правая), Varmilo | **Globe** — переключение языка (на Mac эта клавиша внизу слева) |
| **≣ (меню)**, Logitech | **Globe** — переключение языка |

Язык переключает системная настройка «Нажатие клавиши 🌐 → Переключать источник
ввода»: клавиша Globe (`fn` в Karabiner) просто нажимается с PC-клавиатуры. Другую
клавишу назначают в Karabiner → Devices → нужная клавиатура → Modify events.

Разные клавиатуры различаются по `vendor_id` / `product_id`; список подключённых
устройств: Karabiner-EventViewer или
`karabiner_cli --list-connected-devices`.

**Скорость указателя** — системная настройка, в Karabiner её нет:
Системные настройки → Мышь → «Скорость отслеживания».
