# fastfetch — информация о системе

Конфиг: [`apple.jsonc`](apple.jsonc). Запуск: **`ff`** (alias в fish), открыть: `ffconf`.

Показывает логотип Apple и три блока: **Software** (macOS, ядро, оболочка,
оконный менеджер, терминал, шрифт), **Hardware** (модель, экран, CPU, GPU,
память, swap, диск, батарея), **Misc** (аптайм, число пакетов).

## Как поменять

Каждая строка — элемент в `"modules"`:
```jsonc
{ "key": " CPU", "type": "cpu", "keyColor": "33" }
```
- `key` — подпись (иконки — Nerd Font), `keyColor` — цвет ANSI (31 красный …
  36 бирюзовый, 9x — яркие).
- Убрать строку — удалить элемент; список всех типов: `fastfetch --list-modules`.
- Проверить: `ff`.
