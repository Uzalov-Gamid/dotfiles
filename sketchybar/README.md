# SketchyBar — верхний бар

Конфиг на Lua ([SbarLua](https://github.com/FelixKratz/SbarLua)). Открыть: `skconf` (fish).
Запускается через `brew services`.

```sh
sketchybar --reload                 # применить изменения
brew services restart sketchybar    # если бар пропал / завис
skcheck                             # проверить промежутки и чёлку (fish)
```

## Что на баре (слева направо)

```
 [main 􀙇 …] [🖼 Трек]   ▓▓ чёлка ▓▓   [􀙇 EN] [􀄬] [􀫦 63%] [􀫥 12%] [􀊩 19%] [􀛨 96%] [􀉉 22/10 17:39]
```

| Виджет | Файл | Что показывает | Клик |
|---|---|---|---|
| Спейс + приложения | `items/widgets/aerospace_d.lua` | Текущий спейс, активное приложение (голубое) и остальные в спейсе (серые). `[S]` — сервисный режим AeroSpace | — |
| Музыка | `music.lua` | Обложка + название трека Apple Music. Серое — пауза. Скрыт, когда Music закрыт | **ЛКМ** — карточка с обложкой и ⏮ ⏯ ⏭, **ПКМ** — пауза/play |
| Сеть + раскладка | `system.lua` | Wi-Fi / Ethernet / хотспот, щит = VPN, красная = нет сети; `EN`/`RU` | — |
| Скорость сети | `network.lua` | Цвет иконки: серая — тишина, голубая — трафик, зелёная — > 1 МБ/с | **ЛКМ** — окошко: скорость ↓↑, сеть, локальный и внешний IP, VPN |
| Память | `ram.lua` | Занято, %. Голубая → жёлтая > 60 → оранжевая > 75 → красная > 90 | — |
| Процессор | `cpu.lua` | Загрузка. > 30 жёлтая, > 60 оранжевая, > 80 красная | — |
| Громкость | `volume.lua` | Уровень, динамик меняется, серый = 0 | — |
| Батарея | `battery.lua` | Заряд, ⚡ зелёная — зарядка, красная < 20% | — |
| Дата/время | `calendar.lua` | `ДД/ММ  ЧЧ:ММ` | — |

Попапы закрываются, когда уводишь мышь с бара.

## Устройство

```
sketchybar/
├── sketchybarrc          — точка входа (запускает Lua)
├── init.lua              — собирает бар: bar.lua + items/
├── bar.lua               — сам бар (высота 33, чёрный фон)
├── settings.lua          — ВСЕ размеры, шрифты, частоты, пороги, ширина чёлки
├── colors.lua            — палитра
├── icons.lua             — SF Symbols всех виджетов
├── helpers/
│   ├── capsule.lua       — общий вид капсулы и попапов
│   ├── app_icons.lua     — имя приложения → иконка (sketchybar-app-font)
│   ├── scripts/          — Apple Music (трек, обложка), check_gaps.sh
│   └── event_providers/  — cpu_load: маленькая C-программа для CPU
└── items/widgets/        — по файлу на виджет, порядок — в init.lua
```

## Как поменять

- **Порядок и набор виджетов** — `items/widgets/init.lua`. Правые виджеты
  добавляются **справа налево**: первый в списке — самый правый.
- **Вид всех капсул сразу** (фон, скругление, отступы) — `helpers/capsule.lua`.
- **Промежутки**: между капсулами 7 pt (`settings.lua → paddings.container_paddings`),
  от краёв 9 pt (`paddings.edge_padding`). После правок — `skcheck`.
- **Частоты обновления и пороги цветов** — `settings.lua → widgets`.
- **Иконка** — код SF-символа в `icons.lua` (скопировать из приложения SF Symbols:
  правый клик → Copy Symbol).
- **Иконка для нового приложения** — строка в `helpers/app_icons.lua`
  (имя → `:имя_иконки:` из [sketchybar-app-font](https://github.com/kvndrsslr/sketchybar-app-font)).
- **Попап для своего виджета** — `capsule.attach_popup(item)` + строки
  `capsule.popup_row(...)`, пример в `network.lua`.
- **Все спейсы сразу вместо текущего** — в `items/widgets/init.lua` заменить
  `aerospace_d` на `aerospace`.

## Мониторы

Панель рисуется на **всех** дисплеях (`display = "all"` в `bar.lua`). Виджет спейса
существует в двух копиях, каждая привязана к своему дисплею (`associated_display`) и
показывает спейс своего монитора AeroSpace. При подключении или отключении монитора панель
перезагружается сама. Вырез учитывается только на экранах, где он есть; `skcheck`
проверяет главный дисплей.

## Чёлка (MacBook Air 15")

Вырез занимает x = 646…825 pt из 1470. Правые виджеты кончаются на ~908,
плеер слева — длинные названия прокручиваются в пределах 28 символов, так что
под вырез ничего не попадает. `skcheck` проверяет и это.

Имя Wi-Fi в попапе показывается как «Wi-Fi»: macOS 26 скрывает название сети от
программ без доступа к геолокации.
