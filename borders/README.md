# borders — свечение вокруг активного окна

Конфиг: [`bordersrc`](bordersrc) (это bash-скрипт с параметрами). Открыть:
`bordersconf` (fish). Программа — [JankyBorders](https://github.com/FelixKratz/JankyBorders),
её запускает [AeroSpace](../aerospace/) при старте.

Вместо тонкой рамки у активного окна **мягкое голубое свечение** `#7daea3` —
тот же голубой, которым в баре отмечено всё активное. Оно рисуется *под* окном,
поэтому углы приложений (у всех разное скругление) его прикрывают, и выглядит
это как цветная тень.

## Настроить

| Что | Где в `bordersrc` |
|---|---|
| Сила свечения | первые две цифры в `glow(0x`**`b3`**`7daea3)`: `ff` — максимум, `80` — вдвое слабее |
| Цвет | последние шесть цифр (RGB). Готовые цвета палитры — в комментарии в файле |
| Ширина ореола | `width=8.0` |
| Тонкая рамка вместо свечения | закомментированная строка внизу `options` |

## Применить

```sh
pkill borders; ~/.config/borders/bordersrc &
```

или `alt-shift-;` → `esc` (AeroSpace перечитает конфиг и перезапустит borders).

## Если пропало

```sh
pgrep -x borders || ~/.config/borders/bordersrc &
```

Скриншоты macOS свечение не захватывают — это нормально.
