# tmux — шпаргалка

Конфиг: [`tmux.conf`](tmux.conf), вид — [`theme.conf`](theme.conf). Всё, что помечено ★, — настроено специально,
остальное — стандарт tmux. Плагины ставятся в `~/.tmux/plugins` (не в репо).

![tmux: три панели и плашка PREFIX](../screenshots/tmux-panes.png)

![tmux: плавающее окно floax](../screenshots/tmux-float.png)

## Зачем он нужен

tmux держит терминальные сессии **отдельно от окна Ghostty**: можно закрыть окно
или перезапустить Ghostty — всё, что было запущено (сервер, `docker compose
logs -f`, nvim с открытыми файлами), продолжает работать. Достаточно набрать
`ta`, и сессия на месте. Плюс деление одного окна на панели и вкладки.

## Типичный рабочий процесс

1. В Ghostty набрать **`ta`** — вернуться в последнюю сессию. Если сессий ещё нет
   (например, после перезагрузки) — **`tn`** или `tmux new -s имя`.
2. **Одна сессия — один проект**: `tmux new -s backend`, `tmux new -s infra`.
   Переключаться между ними — `prefix s` (список с превью).
3. Внутри сессии **окна — это задачи**: 1 — редактор, 2 — git/lazygit,
   3 — запуск и логи. Переход — `prefix 1/2/3`.
4. Чтобы видеть код и вывод одновременно, окно делится на панели: `prefix %`
   (справа). Между панелями — `Ctrl-h/j/k/l`, развернуть панель на весь экран — `prefix z`.
5. Быстрая команда без изменения раскладки — **`prefix b`**: плавающий терминал
   поверх всего; тот же `prefix b` его прячет.
6. Уйти, ничего не останавливая, — **`prefix d`** (detach) или просто закрыть
   Ghostty. Вернуться — `ta`.
7. Закончить проект — `tmux kill-session -t имя` (или закрыть все окна сессии:
   ★ tmux не завершится, а переключит в другую сессию).

## Главное за 30 секунд

- **Префикс — `Ctrl-b`** (с Karabiner удобно `Caps + b`: при переназначении Caps в Ctrl).
  Нажал префикс, **отпустил**, потом нажал клавишу команды.
- Пока префикс «взведён», справа горит оранжевая плашка **`PREFIX`** ★.
- Статус-бар **сверху** ★ (тема [`theme.conf`](theme.conf), палитра astronaut):
  ```
  ( сессия ) 1 nvim  2 git          ( PREFIX ) (  папка ) (  ветка )
  ```
  слева — сессия (голубая) и окна (у текущего номер оранжевый, ⛶ = панель развёрнута),
  справа — режим (`PREFIX` / жёлтый `COPY`), папка текущей панели, git-ветка (если это репозиторий).
- Не помнишь клавишу — `prefix ?` (список всех биндов, выход `q`).

```
tn            # запустить tmux (abbr в fish)
ta            # вернуться в последнюю сессию (tmux a)
```

## Сессии — отдельные «рабочие столы» (проект = сессия)

| Клавиши / команда | Действие |
|---|---|
| `tmux new -s school` | Новая сессия с именем |
| `ta` / `tmux a -t school` | Подключиться к последней / к нужной |
| `tmux ls` | Список сессий |
| `prefix d` | **Отключиться** (detach) — всё продолжает работать в фоне |
| `prefix s` | Список сессий с превью, переключение стрелками/`j k`, Enter |
| `prefix $` | Переименовать сессию |
| `prefix (` / `prefix )` | Предыдущая / следующая сессия |
| `tmux kill-session -t school` | Убить сессию |

★ `detach-on-destroy off`: если закрыть последнее окно сессии, tmux **не вылетает**, а
переключает тебя в другую открытую сессию.

## Окна — вкладки внутри сессии

| Клавиши | Действие |
|---|---|
| `prefix c` | Новое окно |
| `prefix 1` … `prefix 9` | Перейти к окну по номеру (★ нумерация **с 1**) |
| `prefix n` / `prefix p` | Следующее / предыдущее |
| `prefix l` | Последнее открытое (туда-обратно) |
| `prefix w` | Дерево всех окон всех сессий с превью |
| `prefix ,` | Переименовать окно |
| `prefix &` | Закрыть окно (спросит `y`) |
| ★ `Ctrl-Shift-↑` / `Ctrl-Shift-↓` | Сдвинуть текущее окно влево / вправо (без префикса) |

★ Окна сами называются по запущенной программе (`fish`, `nvim`, `btop`…), а после
закрытия окна номера сдвигаются без дыр (`renumber-windows`).

## Панели — деление окна

| Клавиши | Действие |
|---|---|
| `prefix %` | Разделить **вертикально** (панель справа) |
| `prefix "` | Разделить **горизонтально** (панель снизу) |
| ★ `Ctrl-h` `Ctrl-j` `Ctrl-k` `Ctrl-l` | Перейти в панель слева/снизу/сверху/справа (**без префикса**, плагин vim-tmux-navigator) |
| `prefix ←↓↑→` | То же, стрелками |
| `prefix z` | **Развернуть панель на всё окно** и обратно (у окна в баре появится ★ ⛶) |
| ★ `prefix Ctrl-←↓↑→` | Изменить размер панели на 10 (можно жать стрелку повторно, не отпуская Ctrl) |
| ★ `prefix Ctrl-h/j/k/l` | То же vim-клавишами, шаг 5 (`Ctrl-l` — шире вправо, `Ctrl-h` — влево) |
| мышь | Перетащить границу между панелями (★ мышь включена) |
| `prefix E` | Выровнять все панели по размеру |
| `prefix Space` | Перебрать готовые раскладки панелей |
| `prefix {` / `prefix }` | Поменять панель местами с соседней |
| `prefix !` | Вынести панель в отдельное окно |
| `prefix q` | Показать номера панелей (нажми цифру — перейдёшь) |
| `prefix x` | Закрыть панель (спросит `y`); или просто `exit` / `Ctrl-d` |

★ Активная панель обведена **голубой** рамкой (как свечение окон), остальные — тёмной.

## Плавающее окно ★ (плагин floax)

| Клавиши | Действие |
|---|---|
| `prefix b` | Показать / спрятать плавающий терминал поверх всего |

Удобно для быстрой команды (`git status`, `htop`), не ломая раскладку панелей. Что
запущено в нём — продолжает жить, когда он спрятан.

## Копирование и прокрутка (vi-режим ★)

| Клавиши | Действие |
|---|---|
| `prefix [` | Войти в режим копирования (в баре ★ жёлтый `COPY`). Прокрутка колесом мыши тоже входит в него |
| `h j k l`, `Ctrl-u` / `Ctrl-d`, `g` / `G` | Двигаться, полстраницы вверх/вниз, в начало/конец |
| `/текст` / `?текст`, `n` / `N` | Поиск вниз / вверх, следующее / предыдущее совпадение |
| ★ `v` | Начать выделение (`V` — строками, `Ctrl-v` — блоком) |
| ★ `y` | Скопировать **сразу в буфер macOS** (`Cmd-V` где угодно) и выйти |
| `q` / `Esc` | Выйти без копирования |

## Конфиг и плагины

| Клавиши / команда | Действие |
|---|---|
| ★ `prefix r` | Перечитать `tmux.conf` (покажет «Config reloaded!») |
| `tmuxconf` | Открыть конфиг (abbr в fish) |
| `prefix I` | Установить плагины из конфига (TPM) |
| `prefix U` | Обновить плагины |
| `prefix :` | Командная строка tmux (`:kill-server`, `:setw synchronize-panes on` …) |

Плагины: `tmux-sensible` (разумные дефолты), `tmux-floax` (плавающее окно),
`vim-tmux-navigator` (`Ctrl-hjkl`). Ставятся в `~/.tmux/plugins`.

## Типичный сценарий

```
tmux new -s do21        # сессия под проект
prefix %                # справа панель для логов / тестов
Ctrl-l / Ctrl-h         # прыгать между ними
prefix c                # новое окно под git / lazygit
prefix d                # ушёл — всё работает в фоне
ta                      # вернулся туда же
```

## Мелочи, которые стоит знать

- `Ctrl-\` в tmux **ничего не делает** ★ — эта клавиша отдана fish (очистка экрана с
  сохранением прокрутки).
- `Esc` срабатывает мгновенно ★ (`escape-time 0`) — важно для vi-режима в fish.
- Цвета 24-bit включены для Ghostty ★, темы в терминале выглядят как задумано.
- Заголовок окна Ghostty показывает `хост:окно` ★.
- Если tmux «завис» на непонятном режиме — `q` или `Esc`, если и это не помогло —
  `prefix :` → `kill-session`.
