# Шпаргалка

## Zsh

| Команда | Что делает |
|---|---|
| `v` | `nvim` |
| `g` | `git` |
| `lg` | `lazygit` |
| `ll` | `eza -la` (список с git-статусом) |
| `tree` | дерево каталогов (2 уровня) |
| `b file` | `bat` без пейджера — быстро посмотреть файл с подсветкой |
| `mkcd dir` | создать папку и сразу перейти в неё |
| `cd path` | это `zoxide`: `cd foo` прыгает в самую "частую" папку с `foo` в пути, а не только в буквальный путь; обычный `cd` тоже работает |
| `z -i` / `zi` | интерактивный выбор папки из истории `zoxide` |
| `tm [имя]` | зайти в tmux-сессию с этим именем (или именем текущей папки), создав при необходимости |
| `reload` | перечитать `.zshrc` без перезапуска терминала |
| `Ctrl+R` | поиск по истории команд |
| `Ctrl+T` | вставить путь к файлу через `fzf` |
| `Alt+C` | перейти в подпапку через `fzf` |
| `Ctrl+Space` | принять подсказку автодополнения (серый текст) |
| `↑ / ↓` | листать историю, учитывая уже набранный префикс |

## tmux

Префикс — **`Ctrl+a`** (не стандартный `Ctrl+b`).

| Комбинация | Действие |
|---|---|
| `prefix + \|` | вертикальный сплит (в текущей папке) |
| `prefix + -` | горизонтальный сплит |
| `prefix + c` | новое окно |
| `prefix + h/j/k/l` | перейти между панелями (vim-стиль) |
| `prefix + H/J/K/L` | подвигать размер панели |
| `prefix + [` | режим копирования (vi-биндинги: `v` — выделить, `y` — скопировать) |
| `prefix + r` | перечитать конфиг `tmux` |
| `prefix + I` | (заглавная i) поставить/обновить плагины tmux |
| `prefix + d` | отсоединиться от сессии |
| `tmux ls` | список сессий (из обычного шелла) |
| `tmux attach -t имя` | вернуться в сессию |

Сессии автоматически сохраняются каждые 15 минут (`tmux-resurrect` +
`tmux-continuum`) и восстанавливаются при следующем запуске tmux —
можно спокойно перезагружать компьютер, не теряя раскладку окон.

## Neovim

Leader — **пробел**.

### Общее
| Комбинация | Действие |
|---|---|
| `<leader>w` | сохранить |
| `<leader>q` | выйти |
| `<leader>e` | файловый менеджер (nvim-tree) |
| `<leader>t` | терминал снизу |
| `Esc` | убрать подсветку поиска |
| `<leader>y` / `<leader>p` | копировать/вставить из системного буфера |
| `Ctrl+h/j/k/l` | переключение между окнами |

### Поиск (Telescope)
| Комбинация | Действие |
|---|---|
| `<leader>ff` | найти файл |
| `<leader>fg` | поиск текста по проекту (grep) |
| `<leader>fb` | список открытых буферов |
| `<leader>fr` | недавние файлы |
| `<leader>fh` | поиск по `:help` |
| `<leader>fd` | список диагностик |

### LSP (появляется, когда сервер подключился к файлу)
| Комбинация | Действие |
|---|---|
| `gd` | перейти к определению |
| `gr` | найти все использования |
| `gi` | перейти к реализации |
| `K` | документация под курсором |
| `<leader>rn` | переименовать символ везде |
| `<leader>ca` | code action (быстрые исправления) |
| `<leader>lf` | отформатировать файл |
| `[d` / `]d` | предыдущая/следующая ошибка |
| `<leader>xx` | список всех проблем в проекте (Trouble) |

### Git (gitsigns)
| Комбинация | Действие |
|---|---|
| `]h` / `[h` | следующий/предыдущий изменённый блок |
| `<leader>gp` | предпросмотр изменения |
| `<leader>gb` | кто и когда менял эту строку (blame) |

### Прочее
| Комбинация | Действие |
|---|---|
| `gcc` | закомментировать строку |
| `gc` (в визуальном режиме) | закомментировать выделение |
| `ys{motion}{символ}` | обернуть в скобки/кавычки, напр. `ysiw"` |
| `ds{символ}` | убрать обрамление, напр. `ds"` |
| `:Mason` | поставить/убрать LSP-сервер или линтер |
| `:Lazy` | статус и обновление плагинов |

## Git

`git` теперь всегда показывает диффы через `delta` (цветной, с номерами строк).

| Алиас | Полная команда |
|---|---|
| `git st` | `status -sb` |
| `git lg` | красивый граф коммитов |
| `git amend` | `commit --amend --no-edit` |

`lazygit` (или `lg` в шелле) — полноценный TUI для git: стейджинг по кускам,
интерактивный ребейз, стэши, всё на клавиатуре.

## Обновление всего разом

```sh
brew update && brew upgrade        # сами инструменты
nvim --headless "+Lazy! sync" +qa  # плагины nvim
tmux <prefix> + U                  # плагины tmux (или заново install_plugins)
```
