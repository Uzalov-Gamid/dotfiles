# btop — монитор процессов

Конфиг: [`btop.conf`](btop.conf), тема: [`themes/gruvbox.theme`](themes/gruvbox.theme).
Запуск: `btop`.

Показывает CPU, память, сеть и процессы (сортировка по CPU), обновление раз в 2 с.

| Клавиши | Действие |
|---|---|
| `j` / `k` | ★ Вверх / вниз по процессам (vim-клавиши) |
| `f` | Фильтр по имени процесса |
| `Enter` | Подробности процесса |
| `k` → выбрать сигнал | Завершить процесс (сначала выделить его) |
| `t` | Дерево процессов |
| `←` / `→` | Сменить колонку сортировки |
| `1` `2` `3` `4` | Показать/скрыть блоки CPU / память / сеть / процессы |
| `m` | Меню (настройки, тема) |
| `q` | Выход |

Настройки удобнее менять через меню `m` — btop сам сохранит их в `btop.conf`.
