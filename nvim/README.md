# Neovim — как пользоваться моим Neovim

Запуск: `n файл` (alias в fish) или `nvim`. Открыть этот конфиг: `nvimconf`.
Изменения подхватываются при следующем запуске (или `:source %` в `init.lua`).

Конфиг: эта папка — [`init.lua`](init.lua), [`after/ftplugin/`](after/ftplugin/), [`colors/palette.lua`](colors/palette.lua). **Без плагинов, без LSP, без автодополнения кода, без
подчёркивания ошибок и автоформатирования** — код пишешь и проверяешь сам, так он
лучше запоминается. Редактор только помогает не отвлекаться: отступы, подсветка,
поиск, запуск.

`Space` — leader. ★ — настроено в конфиге, остальное — встроенное в Neovim.

## Языки

| Файлы | Отступ | `Space r` запускает ★ | Что ещё |
|---|---|---|---|
| Python `.py` | 4 пробела | `python3 файл` (или `.venv/bin/python`, если есть) | линия на 80-й колонке |
| C `.c` `.h` | 4 пробела | `make`, если рядом есть `Makefile`; иначе `cc -Wall -Wextra -Werror -std=c11` и запуск | `.h` — это C, а не C++; линия на 80 |
| Markdown `.md` | 2 пробела | открыть файл в Obsidian | ★ **`Space p` — предпросмотр справа** (glow, в цветах темы), обновляется при сохранении; перенос строк по словам |
| YAML (compose, k8s, Ansible, Actions, Prometheus) | 2 пробела | — | подсветка **колонки** курсора, чтобы ключи стояли ровно; `#` и `:` не сбивают отступ |
| Dockerfile | 4 пробела | `docker build` из папки файла | |
| Shell `.sh` | 2 пробела | `bash файл` | |
| Makefile | **табы** (видны как `»`) | `make` | make требует табы в рецептах |
| Terraform `.tf` `.tfvars` | 2 пробела | — | `.tf` правильно распознаётся как Terraform |
| Jinja / Ansible `.j2` | 2 пробела | — | подсветка `{{ }}` и `{% %}` |
| JSON, TOML, SQL, HTML, CSS, JS/TS, Lua | 2 пробела | — | |
| Сообщение коммита | — | — | линии на 50 (заголовок) и 72 (текст) |

★ **Линии уровней вложенности** `│` на каждом уровне отступа — особенно спасают в
YAML и Python. Их шаг подстраивается под язык (2 или 4).

★ Если в проекте есть `.editorconfig`, его правила главнее этих (поддержка встроена).
В самом `~/.config` он тоже есть: Lua в `sketchybar/` — табы, в `nvim/` — 2 пробела.

## Дерево проекта ★

`Space e` — открыть/закрыть дерево слева ([`lua/tree.lua`](lua/tree.lua), написано
без плагинов). Папки первыми, без `./` и `../`, Nerd-иконки по типам файлов,
текущий файл подсвечен оранжевым, дерево само раскрыто до него.

| Клавиши в дереве | Действие |
|---|---|
| `Enter` / `l` / двойной клик | Открыть файл в основном окне · раскрыть / свернуть папку |
| `h` | Свернуть папку (или перейти к родительской) |
| `a` | Создать файл; имя с `/` в конце — папку (можно `src/utils.c` — создаст и папку) |
| `r` | Переименовать |
| `d` | Удалить — **в Корзину** (спросит подтверждение) |
| `H` | Показать / скрыть файлы с точкой (`.github`, `.env`…) |
| `R` | Обновить |
| `q` | Закрыть дерево |
| `?` | Подсказка по клавишам |

Не показываются никогда: `.git`, `.DS_Store`, `__pycache__`, `node_modules`
(список `NEVER_SHOW` в начале файла). Ширина — `WIDTH`.

## Файлы и поиск (без плагинов)

| Клавиши | Действие |
|---|---|
| ★ `Space f` | Найти файл по имени во всём проекте: `:find main` + `Tab` дополняет, `*` — любые символы |
| ★ `Space g` | Найти текст в проекте (ripgrep): `Space g TODO` → список совпадений снизу |
| `]q` / `[q` | Следующее / предыдущее совпадение из списка |
| ★ `Space b` | Список открытых файлов → номер или часть имени |
| `gf` | Открыть файл, имя которого под курсором (`#include "s21.h"`, пути в YAML) |
| `Ctrl-o` / `Ctrl-i` | Назад / вперёд по местам, где был |

## Терминал и запуск

| Клавиши | Действие |
|---|---|
| ★ `Space r` | Сохранить и запустить файл (см. таблицу языков) — вывод внизу |
| ★ `Space t` | Терминал внизу (например, `docker compose up`, `git status`) |
| ★ `Esc Esc` | Выйти из режима ввода терминала (чтобы листать, копировать) |
| `i` | Вернуться к вводу в терминале |
| `Space q` | Закрыть окно терминала / вывода |

## Редактирование

| Клавиши | Действие |
|---|---|
| ★ `Space w` / `Space q` | Сохранить / закрыть |
| `gcc` / `gc` в visual | Закомментировать строку / выделение (под язык: `#`, `//`, `--`) |
| ★ `>` / `<` в visual | Сдвинуть отступ, **выделение остаётся** — можно жать повторно |
| ★ `J` / `K` в visual | Переместить выделенные строки вниз / вверх |
| ★ `p` в visual | Вставить поверх выделения, не теряя скопированное |
| `=ip` | Выровнять отступы абзаца по правилам языка |
| `.` | Повторить последнее изменение |
| `u` / `Ctrl-r` | Отменить / вернуть (★ история отмен сохраняется после закрытия файла) |
| `Ctrl-n` / `Ctrl-p` в insert | Дописать **слово**, которое уже есть в файле (вызывается только вручную) |

## Сворачивание (YAML, Python, длинные файлы)

| Клавиши | Действие |
|---|---|
| `za` | Свернуть / развернуть блок под курсором |
| `zM` / `zR` | Свернуть всё / развернуть всё |
| `zc` / `zo` | Свернуть / развернуть |

★ Сворачивание по отступам; при открытии файла всё развёрнуто.

## Окна

| Клавиши | Действие |
|---|---|
| `:vsplit` / `:split` | Разделить вертикально (★ справа) / горизонтально (★ снизу) |
| ★ `Ctrl-h/j/k/l` | Переход между окнами — те же клавиши, что для панелей tmux |
| ★ `Shift-←` / `Shift-→` | Окно уже / шире |
| ★ `Shift-↑` / `Shift-↓` | Окно выше / ниже |
| мышь | Перетащить разделитель между окнами |
| `Ctrl-w =` | Выровнять размеры окон |
| `Ctrl-w o` | Оставить только текущее окно |

## Мелочи

- ★ Файл открывается там, где ты его закрыл.
- ★ При сохранении удаляются пробелы в конце строк (кроме Markdown, где два пробела — перенос).
- ★ Скопированное мигает подсветкой; `y`/`p` работают с буфером обмена macOS.
- ★ Внизу: режим, имя файла, `[+]` если не сохранён, тип файла, строка:колонка.
- `:help <что угодно>` — встроенная документация (`:help gc`, `:help :find`).
