# atuin — история команд

Конфиг: [`config.toml`](config.toml). Открыть: `atuinconf` (fish).
[atuin](https://atuin.sh) хранит историю всех команд в базе (с папкой,
временем, кодом выхода) и даёт удобный поиск.

## Как пользоваться

| Клавиши / команда | Действие |
|---|---|
| `Ctrl-R` | Поиск по истории: пишешь кусок команды, стрелками выбираешь |
| `Enter` | ★ Сразу **выполнить** найденную команду (`enter_accept = true`) |
| `Tab` | Вставить команду в строку, чтобы сначала поправить |
| `Ctrl-R` ещё раз (в поиске) | Переключить фильтр: везде / этот хост / эта сессия / эта папка |
| `atuin stats` | Самые частые команды |
| `atuin search --cwd . <текст>` | Искать только среди команд, запущенных в этой папке |

База и ключ шифрования лежат в `~/.local/share/atuin` и в git **не попадают**
(из этой папки в репо только `config.toml`).
