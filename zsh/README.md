# zsh — запасная оболочка

Основная оболочка — [fish](../fish/). zsh остаётся для скриптов и программ,
которые запускают `zsh` сами (установщики, Claude Code и т.п.).

| Файл | Что это |
|---|---|
| [`.zshrc`](.zshrc) | Интерактивная оболочка: история, автодополнение, алиасы, промпт |
| [`.zprofile`](.zprofile) | При входе: `brew shellenv`, XDG-папки |
| [`../starship.toml`](../starship.toml) | Промпт [Starship](https://starship.rs) (папка, git, время команды, Python/C/Lua) |

Единственный файл вне `~/.config` — `~/.zshenv` из одной строки:
`export ZDOTDIR="$HOME/.config/zsh"` — она говорит zsh искать конфиг здесь.

## Если оказался в zsh

| Команда | Что делает |
|---|---|
| `v` | nvim |
| `g` / `lg` | git / lazygit |
| `..` `...` `....` | На 1/2/3 папки вверх |
| `↑` / `↓` | История по началу уже набранной команды |
| `Ctrl-R` | Поиск по истории |
| `reload` | Перечитать `.zshrc` |
| `fish` | Вернуться в fish |

Открыть конфиг: `zshconf` (из fish), промпт: `ssconf`.
